# SIBUSAWA LP

SIBUSAWA STYLE RC 収益不動産LP（静的コーディング版）。

- デザイン：Figma「デザイン案｜PC版」（1440px）／「デザイン案｜SP版」（390px）
- ブレークポイント：〜959px がSPレイアウト、960px〜 がPCレイアウト

## 構成

```
index.html          LP本体
thanks.html         フォーム送信後の完了画面
assets/css/style.css
assets/js/main.js   スライダー・フォームの最小限の制御
assets/img/         Figmaから書き出した画像
```

## 確認方法

`index.html` をブラウザで開くだけで表示できます。
